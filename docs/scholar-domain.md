# 学术工作台领域术语

这里约定产品规划中的名词；这些定义不代表相关功能已经实现。

## 研究活动

**研究课题**：持续追踪的研究问题及其目标。同一课题可以关联多篇小论文、实验和组会。

**小论文**：面向一次学术发表的本人稿件，从问题探索、实验、写作到投稿和修回持续记录。阅读他人的文章称为“文献”。

**毕业论文**：围绕学位要求组织的长期研究与章节成果，可以关联多篇小论文和实验；具体培养节点由用户录入。

**横向项目**：面向合作单位的研究或工程工作，以约定交付物、验收节点和个人负责事项组织。

**课程**：某一学期修读的研究生课程，关联学习记录、作业、考试与资料。

## 过程与证据

**组会记录**：一次组会的汇报要点、讨论、反馈及后续行动，可以关联多个研究对象。

**行动项**：需要执行的一件具体事情，有独立身份、状态、可选期限及来源。会议生成的行动项与工作台中显示的是同一事项。

**里程碑**：具有明确完成条件的阶段节点。期限可以留空；经过日期不表示已经完成。

**研究记录**：一次推导、仿真、实验或分析的目的、方法、结果与判断；记录结果和证明结果的材料需要能相互对应。

**材料引用**：指向外部正文、数据、代码、图表或演示文稿的关联信息。保存引用不表示已经复制、备份或读懂材料。

**文献**：作为阅读和引用来源的他人论文。订阅获取、加入阅读清单、完成阅读分别表示不同事实。

## 展示

**工作台**：用户处理科研与学习事务的一组看板和组件。

**领域记录**：独立于某张卡片而存在的会议、稿件等业务内容。

**组件**：承担一种记录或展示功能的可复用小部件；**卡片**是组件在看板上的一个实例。

**看板**：按任务或主题组织的一页卡片。删除展示与删除领域记录属于不同操作。
