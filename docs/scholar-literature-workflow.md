# 文献、材料与论文全过程实施规格

S15–S17 尚未实施；与 [计划公共指令](PLAN-scholar.md#waker-执行契约) 合用。前置阅读：记录规格、S10 关联契约、D3/D5/D6/D24/D26/D28/D36；UI 另读 D10/D16/D20。

## S15 阅读与检索

**目标与范围**：深化 literature-records 与 paper-feed，修改相关 contracts、host 查询/交换与 testing。保持现有阅读阶段兼容，不自动把待读改为理解。

**数据与操作**：文献增加 DOI、arXiv id/版本、正式出版物与预印本的关联；阅读条目有稳定 id、章节/页码/公式位置、笔记、个人理解、疑问、待复现事项和日期。按课题与实际阅读范围回看，问题可转现有行动项。订阅支持保存名称、查询条件、来源和分类，不只固定一个分类。

**去重**：优先规范化 DOI，再比较 arXiv 主 id，URL 与标题相似只给候选；预览重复原因和双方字段，由用户选择保留、补充或建立版本关系。合并要迁移引用并保留来源，不以同标题直接删除记录；批量导入逐条展示错误。

**验收**：预印本与正式稿、同 DOI 不同 URL、中英文相似标题、无标识记录；实际只读两节不显示全文已读；订阅加入仍为待读；断网不丢笔记；旧包导入与关联重映射。

## S16 外部文献与材料

**目标与范围**：通过宿主提供方加入 DOI 元数据补全与 Zotero 本地只读选择，扩展材料契约与引用界面。更改受保护 HTTP 或地址安全边界前按 AGENTS 确认；不直接让组件联网。

**DOI**：先展示候选元数据及来源和查询时间，用户选择补入；不覆盖个人笔记，冲突字段保留当前值供选择。缓存和 429/Retry-After 处理在宿主完成，认证信息不放 URL 或日志。Crossref 的联系邮箱只有用户明确配置才发送，不从 Git 身份提取。[Crossref 官方接入说明](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication)

**Zotero**：用户手动启用连接后读取本机 API、选择 library/collection/条目、预览导入，不读 SQLite。保存提供方、库、条目 key 和接口版本来源，不把外部版本与本地修订号混用；本地 API 和 Web API 的缓存隔离。Zotero 未启动、未启用、无匹配、超时分别提示。云端 localhost 不指向 Windows，界面明确所连设备；首批不加入 Web API 写回或端口转发。[Zotero Local API](https://www.zotero.org/support/dev/web_api/v3/local_api)

**材料**：材料引用区分网页与本地路径，含标题、用途/类型、设备标签、可选版本和最后核查状态。显式选择文件或填写路径，不扫描磁盘。只有宿主明确支持的能力可打开；没有能力则复制路径并说明。路径文本不进入 widget.open，也不作为 shell 参数执行。跨设备可重新定位并保留旧引用记录。备份包含引用元数据、不包含文件正文，导出预览指出路径等私人信息。

**验收**：本机 Zotero 选取、断线、403、缓存来源变化；DOI 查询重试和冲突；本地路径不被当作网页执行；云端不能访问的材料显示设备不匹配；备份不隐含正文。无需用户库也能通过合成服务数据与真实接口独立核查完成回归；不以外部可用性决定核心测试。

## S17 投稿修回与毕业论文

**目标与范围**：深化 manuscript-records、thesis-records 与相关 contracts/host/testing；复用 S10–S14 的关联、行动项和证据引用。

**修回**：每轮保存刊会、日期、决定、期限与材料检查表；审稿意见条目增加审稿人称呼/编号、意见编号、修改位置、回复草稿、行动项及证据引用。每条可标待处理/处理中/完成/不采纳，不采纳附理由。意见转任务复用稳定条目 id 防重复；完成行动项不自动表示回复已完成。导出 Markdown 显示选定轮次、意见、改动、回复、证据与缺失项。

**投稿**：用户定义正文、补充、声明、图表、代码数据说明等检查项；冻结提交材料清单及版本说明，旧轮次不覆盖；提交与接收状态由用户维护，不登录投稿系统。具体期刊要求由用户维护，不把通用模板当强制规定。

**毕业论文**：章节关联课题、稿件、研究与图表证据；待补实验关联方案和行动项；培养节点与材料清单可配置。完成状态人工维护，不按日期、页数或关联论文数判定毕业资格。

**验收**：两轮修回、相同意见重复转任务、反复改稿、证据缺失、来源更新、旧轮次导出；章节能找到成果，删除章节不删除成果；备份与旧投稿记录保持兼容。

## 外部来源使用边界

来源核查日期为 2026-11-14；实现时重新核查版本和限流。arXiv 沿用宿主 Atom 解析与官方查询规则，按官方要求限制连续请求，不抓取受限全文。[arXiv API 手册](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md)

OpenAlex 是后续可选提供方，其配额和密钥要求以当时官方文档为准，不作为本批验收前提。[OpenAlex 认证说明](https://help.openalex.org/api/authentication/)
