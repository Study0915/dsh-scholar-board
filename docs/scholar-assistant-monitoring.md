# DSH 会话辅助与只读监控实施规格

S24–S25 尚未实施；与 [计划公共指令](PLAN-scholar.md#waker-执行契约) 合用。先读 D1/D3/D5/D6/D24/D28/D31/D32/D36、宿主工具注册模块与实际宿主类型；UI 读 D10/D16/D20。

## S24 DSH 会话辅助

**范围**：通过 `packages/host/src/tools/` 既有注册机制扩展选定记录读取与建议提交，新增 host 建议校验、预览/确认 UI，相关 contracts/runtime/widgets/testing。复用现有 DSH 模型与会话，不另设模型密钥和调用费用配置。

**输入**：由用户显式选择记录/条目与用途（提纲、行动项、证据缺口、修回结构、周报）；提供类型/id/修订、来源片段与允许写入的目标。只传选定内容；材料默认传引用，不自动读取全文、整库或云端不可访问路径。外部文本视为待整理材料，不能改变工具权限。

**输出契约**：建议有稳定 id、用途、来源引用、目标记录及 baseRevision、建议文本或类型化新建/修改操作；引用应能定位回记录/条目。没有来源的推测标“建议/待核查”，不伪造引文、实验数据、阅读状态和期限。生成仅保存候选，不直接提交业务状态。

**确认事务**：预览展示来源、现值、建议值、将新建/修改的对象；用户逐项选择后确认。服务端重查修订与允许字段，过期建议保留草稿并提示冲突，不覆盖新内容；同一建议确认幂等。一次建议包含多个写入时明确事务边界，失败不能留下未报告的部分成功。取消无业务写入。

**宿主兼容**：工具服务缺席显示不可用；宿主若没有把选定内容交给会话的公开接口，则提供明确的复制提示词与返回结果预览入口，并记录该能力未接通，不查询宿主私有 DOM 或另建模型服务。工具的写入不走免审旁路；记录正常手动编辑继续使用既有能力，不新增无关确认弹窗。

**验收**：生成一份有来源提纲、反馈转行动项、证据缺口与修回草稿；取消、部分选择、重复确认、两页面修订冲突、恶意材料指令、工具缺席、无来源输出、外部路径不外传；对每个写入检查来源与 revision，不以生成接口调用成功冒充功能验收。

## S25 只读实验监控

**范围**：host 数据源/提供方、run 记录的外部来源、监控卡与相关 contracts/testing；首批选定 JSON/CSV 清单与 MLflow 只读 REST。组件仍经宿主读取，不直接联网。

**连接**：用户配置连接别名、明确服务地址或选定文件及映射规则；本地文件使用 S16 已确认的选择和读取能力，不遍历目录。凭据由现有认证/秘密服务管理，不入记录、URL、备份和日志；需要的新网络边界先评审。host 验证目标和响应限额，遵守取消、超时、并发、刷新、暂停与健康记录机制。

**映射**：外部运行稳定身份由连接 id、实验 id 与运行 id 组成，映射状态、配置、指标、更新时间、日志/产物链接。JSON/CSV 导入使用成熟解析库，预览字段映射、错误行、缺失单位与行数限额。已导入项按外部身份识别，重复刷新不创建重复运行；同名不同 id 不合并。

**事实边界**：远端原始状态与显示状态并列保存，无法映射显示未知；失败、陈旧、断线、等待刷新分别呈现。连接只读，监控快照与人工维护的 run 分开；人工选择后才把快照/证据关联到运行，并保存来源和采集时间，不静默覆盖人工字段。产物链接不表示已下载或核查；外部删除不级联删除本地记录。

**验收**：JSON/CSV 与 MLflow 两类接入，畸形文件、错误指标、超时/断线/恢复、重复刷新、外部删除、暂停后不继续请求、连接删除保留本地证据；确认无启动/停止/重跑接口，独立在线探针不决定离线回归。

官方参考：[MLflow Tracking](https://www.mlflow.org/docs/latest/tracking/)、[REST API](https://www.mlflow.org/docs/latest/api_reference/rest-api.html)。于 2026-11-14 核查，实施时记录实际服务版本并重查响应，不假设所有部署都开放同一认证与产物能力。
