# 横向交付、分工与标准实施规格

S18–S20 尚未实施；与 [计划公共指令](PLAN-scholar.md#waker-执行契约) 合用。目标是个人维护的团队工作记录，不增加账号和访问权限。前置阅读：记录规格、S10 导航与 S14 证据契约、D3/D5/D6/D24/D36；UI 读 D10/D16/D20。

## S18 需求与交付

**范围**：深化 project-records 与相关 contracts、host records 校验/查询/交换、testing；复用现有行动项与会议，不为项目复制另一套任务系统。

**需求**：稳定条目 id、项目内需求编号、标题、描述、版本、来源记录/材料、待确认/已确认/已取消状态、验收指标、单位、阈值或判定说明、测试方法、关联任务。需求变更保存前后版本、原因、日期、影响、沟通依据与用户填写的确认情况；历史不原位覆盖。

**交付**：交付物版本关联需求、实现代码/材料、测试报告、已知限制、交付时间和验收意见。保持草稿/评审中/已交付/已验收状态；已交付不等于已验收。一次验收失败保留记录与待补事项，不能被下次成功覆盖。冻结材料清单是引用与版本快照，不表示复制外部正文。

**操作**：从需求/问题创建行动项，项目任务条目可显式关联或转换为共享行动项；转换前预览、稳定来源防重复、不自动迁移所有旧条目。沟通结论引用会议或保留独立来源；详情显示需求→任务→测试→交付→验收。默认模板提供算法、仿真验证、原型软件、测试报告、技术报告、演示材料；不包含合同金额和客户敏感默认数据。

**验收**：算法需求从 v1 改到 v2，旧交付仍可看 v1 依据；测试失败、重新交付、分批验收、材料缺失；旧 project 内嵌 tasks/communications 不丢失；跨视图状态、导出预览、备份重映射和并发保存。

## S19 分工与交接

**范围**：在宿主增加成员目录的公开读写契约，project/action/meeting 的分工与评审字段使用成员引用；记录与成员一并备份，继续修订校验与容量预算，不保存到单张卡私有 state。持久化方向如有变化先写 ADR。

**数据**：成员稳定 id、显示称呼、角色说明、启用状态；首批不要求电话、邮箱和真实姓名。事项可有一位负责人、多位协作人和待确认人；这些值是个人记录，不是认证身份或权限。`lastEditedBy` 保持组件来源意义，不用它冒充成员本人编辑。

**评审与交接**：评审条目记录对象/版本、称呼、日期、意见、决定及后续行动；交接清单包括当前进度、材料、操作说明、已知问题、待办与接手人。生成交接草稿必须预览选择范围，交接确认由用户手动记录。成员改名按 id 显示新称呼，历史冻结版本保留当时摘要；停用可查，不级联删除分工。

**验收**：同名成员、成员停用、称呼变更、无负责人、任务转交、交接未确认与已确认；合成项目多人分工追溯；备份 ID 重映射覆盖成员，旧包没有成员时正常导入。不得用界面成员字段实现“已由某人审批”的身份断言。

## S20 标准与技术资料

**范围**：增加 `standard` 记录与标准阅读卡，contracts/host 校验、检索、备份和画廊同步。首批人工维护书签与版本，不引入受限全文下载或全网标准抓取。

**数据与行为**：组织、规范编号、标题、Release、版本号、发布日期、来源 URL；章节条目记录定位、理解、适用设计、待核查问题及关联需求/研究/交付。Change Request 是单独的依据条目，不能与 Release 或版本号混为一项。新版本作为新记录或有独立 id 的版本条目保存，与旧版建立关系；影响待核查，不覆盖已采用的依据。

提供查询外链与用户手工“已核查到某版本”的日期，不用上次读取成功暗示版本最新。IEEE 元数据接口须按实际授权接入，标准全文访问权独立；3GPP 自动更新若没有可靠官方途径，保留手工路径并记录限制，不抓取失败后伪造更新。

**验收**：同一规范两个 Release、同 Release 多个版本、CR、条款定位、引用缺失、旧版依据保留；标准→需求→实验→交付可追溯；新类型完整导出导入。

## 官方依据

接口事实于 2026-11-14 核查，实现时重查授权与版本：[IEEE 可用 API](https://developer.ieee.org/docs)、[3GPP 版本编号](https://www.3gpp.org/specifications-technologies/specifications-by-series/version-numbering-scheme)、[ETSI 的 CR 说明](https://portal.etsi.org/new3g/specs/cr.htm)。元数据能力不代表全文授权，产品保存引用不代表完成合规审查或合同验收。
