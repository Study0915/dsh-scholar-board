# 科研证据与通信模板实施规格

用户于 2026-11-14 确认的 S10–S14 任务说明；这些功能尚未实现。与 [PLAN-scholar](PLAN-scholar.md) 的 Waker 公共指令共同使用。每项先读 D3、D5、D6、D10、D16、D20、D24、D32、D36 和现有记录规格；真实源码为当前接口依据。

## S10 统一关联与导航

**目标与范围**：修改 records 契约、宿主查询与相关 client/runtime 访问层，接入九类记录卡及总览；测试与规格随行为更新。保留沙箱和组件格式，不在组件之间直接访问 DOM 或 state。

**行为**：统一选择器支持标题搜索、类型筛选、勾选、取消和已选预览；当前记录不允许关联自身，同一引用去重。读取对象含活跃与归档记录，归档标记可见；回收站记录保留引用并标记，永久缺失保留 id。请求失败、截断结果、无匹配分别呈现，不把失败当作来源删除。补齐研究和文献等卡的关联编辑，不只展示底层字段。

**接口与导航**：复用 `RecordRef`，由宿主统一解析标题、生命周期和反向引用；按需要扩展公开查询而不让每卡重复全库扫描。运行时新增可查询的“打开记录”能力，传目标类型与 id，由浏览器通过宿主控制的详情表面打开；没有目标卡片也可访问。返回恢复原筛选、滚动、焦点和草稿。能力缺席显示可见说明，不创建第二份记录。对外接口必须让用户组件同样可调用。

**异常与兼容**：导航时有未保存输入，允许保存、保留草稿后离开、取消。查询排序稳定，容量范围内支持分批读取；旧卡不声明导航能力仍可正常使用。新关联字段只增量写入，不覆盖未在当前表单修改的原字段。

**验收**：文献→研究→稿件→返回；目标没有卡片；目标归档/删除/恢复；读取失败与重试；两页面修改；键盘操作；刷新后关联保留；原包导入重映射；窄盒中操作可见。源码相关文件接近 750 行时先提出目录内职责拆分并按停止线确认，不继续加功能。

## S11 课题与问题

**目标与范围**：新增 `topic` 记录与课题卡，扩展 contracts、host records 校验/查询/交换、组件画廊和 testing；不改已有默认看板。课题字段为标题、研究问题、目标、假设、当前判断、下一步、关联与材料；问题条目有稳定 id、内容、待解/调查中/已解决状态及可选行动项引用。

**行为**：课题详情聚合相关文献、研究、稿件、会议和项目；反向关联也可查。问题转行动项保留课题和条目来源，已有行动项时进入同一事项。用户关闭问题与完成行动项分别记录，界面提示差异，不自动推断科研问题解决。

**异常与兼容**：重复点击转任务必须幂等；跨记录创建失败不留下伪成功关联，重试能找到已经创建的事项。删除课题不级联删除成果；问题移除后行动项保留来源缺失说明。

**验收**：同一课题关联两篇稿件、多个研究记录和会议；问题生成任务不重复；任务状态跨视图一致；归档、回收站、备份、ID 重映射及旧类型回归。完成后更新记录规格；没有源码与完整验证证据不勾选本项。

## S12 研究方案与运行

**目标与范围**：新增 `run` 记录与运行卡；现有 `research` 保留并增加方案字段。覆盖 contracts、host 校验/查询/交换、相关 widgets 与 testing；继续现有存储和预算。

**数据契约**：运行有标题、方案引用、状态 planned/running/succeeded/failed/cancelled、代码仓库与提交、数据集及划分/版本、模型检查点、配置与环境、种子、评估集合、起止时间、观测指标、日志/产物引用、失败原因与备注。时间允许未知，成功不要求补造时间。计划参数属于方案，实际配置与观测指标属于运行。

每条结果标明单次运行或统计汇总；汇总注明来源运行、统计方法、样本数与离散度是否可用。手工汇总缺少原运行时明确标记，不编造种子。指标保持名称、值、单位及定义，未给出值与数值零分别处理；文本值允许保存，比较时单独处理。

**操作**：方案可创建新运行、查看同方案运行、复制配置建立新计划；复制不复制成功状态、观测值、起止时间和产物。状态由人工或以后明确接入的数据源维护；本项不执行脚本。失败与负结果照常归档检索。

**兼容与异常**：已有 research 的指标与结论保留原义，不自动迁移成 succeeded run。类型新增时同步类型列表、来源允许范围、计数、用量、搜索、备份和重映射。运行引用缺失可编辑重选，保留历史信息；超过容量原子拒绝并保留草稿。

**验收**：一个方案三次运行，分别成功/失败/取消；不同数据版本；零指标、无指标与文本指标；汇总来源缺失；复制计划无结果污染；并发保存、重启、导出导入和旧 research 原值保留。

## S13 通信专业模板

**目标与范围**：在 contracts 定义版本化模板，在 host 保存个人模板，runtime 提供公开访问；研究/运行编辑器应用模板。模板不属于一次实验，不占用 run 身份；其存储、限额与备份在本项规格修订中明确记录，沿用宿主原子写入，不放进某卡私有 state。

模板含稳定 id、名称、方向、版本与字段定义。字段含键、显示名、类型、可选单位、说明、适用条件和建议选项。用户可复制内置模板、修改、保存个人模板；应用前预览，已填写的同名值默认保留，替换由用户选择。记录保存所用模板 id/版本和应用时字段快照；模板更新不改旧记录。首批字段类型限文本、数字与选项，不运行用户表达式。

| 模板 | 字段与检查提示 |
|---|---|
| 通用信号处理 | 采样率/带宽与单位、信号模型、噪声和 SNR 定义、同步/估计误差、量化、Monte Carlo 次数、阈值、评价集合 |
| 光通信/低比特检测 | 调制、符号率、链路/器件条件、接收方式、量化位数、参考质量、强弱目标条件、时延误差；按任务选择 BER/EVM/OSNR、虚警率与检测概率及阈值校准/评估集合 |
| 语义通信/ASR | 数据集划分、预处理、模型/检查点、预算、种子、信道、解码规则、文本归一化、WER/CER/语义指标、参考与预测材料 |
| 无线扩展 | 信道、天线、CSI、功率、SNR 定义、频谱效率、能效和复杂度；后续模板，不阻塞前三类 |

**验收**：前三类模板各完成一条方案与运行；只填适用字段；未知单位与非适用有明确说明；模板编辑、删除、版本更新不破坏旧记录；个人模板备份恢复；不将模板勾选情况称为公平性、有效性或创新性证明。

## S14 比较与图表证据

**目标与范围**：新增运行比较视图，扩展稿件图表条目和研究结论的证据引用；覆盖 contracts、host、相关卡片与 testing，不加入训练执行或自动论文写作。

**比较规则**：用户选择运行并标记基线、消融、其他方案；展示数据划分、信道/预处理、训练预算、解码、指标定义、单位和统计方法。明确不同、未知分别提示。只有用户确认同口径、数值和单位一致时才允许计算指定方向的差值；不自动换算 dB、不混合百分数与比率、不把多 seed 均值当单次值。默认不排名，零基线不计算相对提升。

**证据契约**：引用记录类型/id/修订、可选条目 id 与材料 id。图表增加运行引用、数据材料、绘图代码仓库/提交与结论说明；结论增加依据和适用边界。引用版本与当前版本不同显示“来源已更新”，冻结版本保存明确的依据摘要，不承诺保存外部文件或全部历史记录。图表编号保留原形，不因排序自动重编号。

**验收**：固定实际虚警率下比较检测概率，阈值校准集合与评估集合分开；ASR 不同划分/解码出现差异提示；单次和均值不混算；来源修改、删除、导入重映射；图表能回到对应运行与材料。从课题到稿件图表和组会完成一次完整流程，批次 A 才可验收。
