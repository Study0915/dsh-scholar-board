# 日常工作台与部署实施规格

S21–S23、S26 尚未实施；与 [计划公共指令](PLAN-scholar.md#waker-执行契约) 合用。前置阅读：领域与记录规格、S10 导航、体验要求、D5/D10/D16/D20/D21/D24/D35/D36；安装前读 cloud-environment 和当前宿主官方帮助。

## S21 总览与快捷处理

**范围**：research-overview、统一搜索/导航、相关 contracts/host 查询、testing；复用现有记录数据源，不为总览另存事实副本。

总览按今天/本周、无期限、受阻和等待反馈组织行动、课题、运行、修回、交付和培养节点；类型间重复出现同一行动项只保留一个可处理入口。用户可选择显示区域、保存筛选和最近访问；这些偏好属于用户工作区视图，不修改记录状态。

统一搜索支持标题/已纳入检索的正文、类型、关联课题、生命周期与日期范围；返回结果标明来源、命中摘要及截断情况。快捷新建保留当前关联上下文，必填项只要求相应记录的最小字段。周计划引用既有行动项，增加周内安排与备注，不复制任务；手工周报草稿选定范围并注明记录来源，不把未完成写成已完成。

**验收**：各类事项进入总览、取消/完成状态正确；同任务去重；无期限与受阻筛选；返回位置、中文/英文/长标题、容量内分页；保存失败不丢输入。使用 10/30 张卡与 0/1/50/200 条合成记录，按既有体验测量协议记录请求、挂载、资源释放和响应时间。

## S22 课程与事务

**范围**：course/chore/thesis 编辑与相关 contracts/host/testing；保持旧校园事务卡和自由文本不自动迁移。

课程增加学期与可选起止日期、重复课次、例外日期、作业/考试的计划日期与实际完成、补交说明、学习笔记及材料。重复课次保存规则与例外，不无限生成记录；调整单次与整个系列区别展示。学期归档保留未完事项提醒，跨学期同名课程不合并。

学位材料清单可按开题/中期/预答辩/答辩或自定义节点组织；材料有状态、来源与待确认条件。个人事务提供会议出行、报销材料、实习/申请模板，保存期限、清单与材料，不默认加入身份、证件、财务等敏感字段。不自动判断学分、毕业资格或报销合规。

**验收**：跨学期、补交、取消课次、单次修改与系列修改；材料缺失、无日期；模板不覆盖旧卡；关联与备份恢复。

## S23 日期与提醒

**范围**：复用既有 Due 语义并统一格式化与计算层，修改相关 contracts/model/host/runtime/widgets 和 testing；不在各组件重复实现时间计算。

纯日期表示用户指定的日历日，不能通过 UTC 转换漂移；具体时刻保留时区/偏移。无期限不倒计时，经过日期不自动完成。提醒保存目标记录/条目、触发时间、稍后时间与已处理状态；去重标识覆盖目标及该次触发。提醒操作不改变业务完成状态。

首批在工作台打开时计算并显示到期/错过事项，页面关闭期间不承诺后台系统通知；重新打开能看未处理事项。支持用户选定事项导出 `.ics`，采用成熟格式库；纯日期使用全天事件语义，具体时刻使用明确时区/UTC，稳定 UID 避免重新导出变成无关事件。导出预览显示包含的标题和日期，不默认包含正文与私人路径。

**验收**：Asia/Shanghai、跨日、夏令时地区、纯日期、空期限、稍后处理、修改期限、重复提醒、刷新去重和日历往返解析；不要只测试实现内部字符串。

## S26 公开安装与升级准备

**范围**：安装/升级验证工具、隔离宿主测试、可选工作台模板、双语 README、用户指南、版本与兼容说明；产品问题作为独立修复任务，不以改测试阈值通过。

**矩阵**：在 Windows 和 Ubuntu/Debian 的隔离宿主使用实际验证过的 Node、DSH、浏览器版本测试；未测组合明确标记。安装命令先核对该宿主版本的 `plugin add --help`，包含实际需要的 profile 参数，不复用过时 ADR 命令示例。

**过程**：全新安装→启用→选择模板→合成记录→备份→升级到待验收版本→确认记录、关联、布局和草稿→停用/启用→导出恢复。升级测试必须有两个明确版本；只有安装一个本地包不能宣称升级通过。真实用户 `.dsh` 只读，不重启主服务。

**模板与说明**：用户显式选择科研、组会、稿件、毕业论文、项目或课程组合；加入模板不覆盖已有看板。附首次使用、备份恢复、跨设备材料限制、Zotero/监控配置、AI 审阅、离线能力和常见问题。首次运行不要求连接外部服务。

**证据与发布**：记录命令、退出码、版本、测试 home、数据前后比较、截图与已知限制；公开截图用合成数据。每批积累兼容证据，S26 汇总。产品仓库 PR/合并按既有授权，版本标签、npm、上游操作和真实环境安装保持各自授权边界。准备就绪不等于已经发布。
