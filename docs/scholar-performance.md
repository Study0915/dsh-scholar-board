# 学术看板的性能测量（S01）

更新日期：2026-11-13。本文记录 [PLAN-scholar.md](PLAN-scholar.md) S01 的性能测量方法、环境、读数与比较规则。测量对象是被测代码 `952550b` 的默认学术看板，不覆盖安装后的桌面宿主、云端 CI 与外部网络。报告是本地证据，不随仓库分发。

## 测什么

一次完整动作是「打开学术看板 → 卡片全部接上运行时令牌 → 离开看板 → 接口安静 → 空窗口」。同一次会话连做三轮，每轮量：

| 指标 | 口径 |
|---|---|
| 挂载 | 从点击「看板」到全部卡片 iframe 接上令牌的毫秒数 |
| 请求 | 宿主接口（`/api/`）、宿主静态资源、外部站点、内联资源分开计数 |
| 长任务 | `PerformanceObserver` 的 `longtask`，按轮切开，记条数、总时长与最长一条 |
| 资源释放 | 离开后看板视图是否卸载、iframe 是否归零；页面堆（先收垃圾）与宿主堆／常驻内存 |
| 空闲 | 接口安静后再等 3 秒：这段时间必须没有宿主接口请求、没有残留 iframe |

失败条件（探针以非零退出）：宿主本地 4xx/5xx、非中止的宿主请求失败、离开后仍有接口请求、卡片 iframe 没摘掉、控制台错误或警告、未捕获异常。切视图时旧卡片中止还在加载的 document 属于预期，只计数不判失败。

## 环境与方法

| 项 | 值 |
|---|---|
| 被测代码 | `952550b`（`main`） |
| 运行 | Node `v24.18.0`，Chrome `138.0.7204.157`，无头，视口 `1440×900` |
| 宿主 | 每次运行起一个独立的临时宿主（独立 `DSH_HOME`）与浏览器上下文，不连外部网络 |
| 看板 | 默认学术看板 9 张卡，另加一张运行成本卡读宿主读数，共 10 张 |
| 轮次 | 每次会话三轮；本文记两次会话，共六轮 |

命令（`dsh` 需在 `PATH` 上，浏览器由 `CHROME_PATH` 指定）：

```
node scripts/build.mjs
node packages/testing/performance.cjs --cycles 3
```

测量脚本在 `packages/testing/performance.cjs`；判定逻辑是 `judge()`，由 `packages/testing/test/performance.test.ts` 覆盖。报告写到 `.debug/s01/perf-<时间戳>.json`（gitignored），启动地址里的令牌在写入前已替换。

两次会话的公共读数：

- 首轮「打开→离开」期间 27 次宿主接口请求，其中 10 次是卡片 document，其余为看板快照、可见性、事件流与卡片设置／调用；外部请求 0 次。
- 接口安静耗时 1.0–1.2 秒，排水窗口内一次性请求 0 次；六轮空闲窗口均为 0 请求、0 iframe、0 长任务。
- 宿主 4xx/5xx 0 次，非中止的请求失败 0 次，控制台错误与警告 0 条；被中止的旧 document 每次 3 个，属于切视图的预期行为。
- 页面堆在 25–27 MiB 之间，离开后回到 26 MiB；没有随轮次增长。
- 宿主堆在 165–215 MiB 之间波动，常驻内存随宿主自身的分配器起落（如 487 → 338 MiB），同一轮打开与离开一致，没有逐轮累积。

## 结论

- 没有复现出需要先修的性能缺陷。挂载三轮内趋于稳定，离开后视图、iframe 与接口请求都归零，页面堆回到同一水平。
- 打开时偶有 1 条 51–68 ms 长任务：六轮中三轮各出现 1 条，第三轮都没有；低于造成交互卡顿的量级，记录为观察项，不据此改动代码。
- 通用体验问题与上游候选见 [upstream-candidates.md](upstream-candidates.md)；本次未改产品源码。

## 同环境比较规则

后续改动若声称改善性能，按同一环境比较：

1. 同一台机器、同一浏览器与实际版本、同一视口、同一轮次；先 `node scripts/build.mjs`。
2. 改动前后各跑两次会话，各三轮；比较挂载中位数与离开后的堆，而不是单轮最好值。
3. 只有两次会话朝同一方向变化、且没有把失败条件从通过变成不通过，才可写成改善。
4. 记录被测提交与报告文件名；跨提交比较时注明两次的构建是否相同。

## 未覆盖与残留风险

- **一次未定位的 400**：2026-11-11 的 S01 基线里出现过一次 `400 Bad Request`，当时未定位到具体资源；本轮六轮与在此之前的多轮都没有复现。保留为待复现项：再出现时同时保存宿主日志、响应路径与当轮报告，不先猜原因。
- 测量是本地临时宿主上的无头浏览器，不含安装后的桌面宿主、真实显示缩放、节能模式与云端 CI 机器。
- 外部网络不参与基线：文献订阅等外部请求失败不影响本地读数，也不在本测量范围内。
- 宿主堆与常驻内存的单轮跳变（如第二轮升高、第三轮回落）来自宿主进程自身的分配与回收，样本量不足以区分具体原因；只按「同一轮打开与离开一致、无逐轮累积」判断释放，不据此推断更细的内存行为。
