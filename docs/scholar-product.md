# 通信硕博个人科研工作台产品规划

更新日期：2026-11-14。用户于 2026-11-10 确定个人优先、短记录与外部正文混合；2026-11-14 确定优先深化科研证据与通信模板，同时完善横向交付、团队分工记录、日常事务、DSH 会话辅助与只读监控。实施状态以 [PLAN-scholar](PLAN-scholar.md) 为准，术语见 [领域术语](scholar-domain.md)。

## 使用目标

打开工作台能够回答当前研究什么、本周推进什么、上次组会留下什么问题、结果依据在哪里、稿件卡在哪里、下一次需要交付什么。重点贯通课题→文献与问题→推导/实验方案→运行与结果→图表证据→组会行动→稿件与毕业论文。

独立维护 `dsh-scholar-board`，用户自由组合卡片。新增模板由用户选择，已有看板和内容保持原样；研究方向、学校培养节点、期刊要求、项目阶段和期限由用户维护。云端负责开发与验证，本机是主要日常使用位置，并准备供公开用户安装。

工作台编辑要点、理解、问题、方案、进展与行动；Word、LaTeX、Markdown、PDF、代码、数据和演示正文在外部维护。当前材料只支持 http/https 引用，本地材料与 Zotero 连接是 S16 计划，保存引用不等于复制正文、备份或核查其内容。

## 产品选择与边界

**通信定制**：统一字段和证据契约配可选模板，优先光通信、信号处理、语义通信/ASR，保留无线扩展。允许自定义指标与单位，不强制所有研究填写同一套参数。模板的检查提示不能证明公平性、有效性或创新性；单次运行、重复、统计均值和方案变体必须区分。

**文献学习**：实际阅读章节、理解与问题由用户维护；订阅、入库、阅读与理解分别记录。摘要不会变成个人理解；DOI/arXiv 和 Zotero 首先解决来源与录入，不自动声称获取合法全文或读懂论文。

**科研证据**：研究方案保存计划，运行保存实际配置与观测。失败和负结果保留；比较显示评估口径差异和未知。结论、图表与稿件引用稳定来源和版本，不编造结果或进展。

**横向与协作**：个人维护成员称呼、负责事项、沟通结论、评审与交接；称呼不代表认证身份。需求版本、验收指标、测试、交付与验收状态可追溯，默认模板不包含合同金额或敏感业务正文。经费、多人审批与在线协同另行决定。

**AI**：复用 DSH 会话处理选定内容，建议带来源和待写入变化，用户预览选择后经修订检查保存。没有公开宿主能力时明确显示限制，不接入私有 DOM 或自行增加模型服务。

**只读监控**：连接已有 JSON/CSV 清单或 MLflow 服务，读取状态和结果摘要，显示更新时间与过期。外部数据作为有来源的快照，用户选择关联证据，不静默覆盖手工记录。运行登记和监控不执行程序。

**日期与事务**：期限、学位要求与投稿要求由用户维护；纯日期与时刻语义分开。首批提醒限工作台内展示及日历导出，不承诺关闭页面后的系统通知。

账号、多人实时编辑、云同步、完整论文编辑器、自动投稿、自动科研结论、训练/仿真执行与远程任务控制不在本轮范围。公开发布准备不扩大上游、标签或 npm 发布授权。

## 记录与体验要求

- 记录有稳定身份和修订，由宿主权威写入，跨看板只显示同一份事实；移除卡片不删除记录。共享访问使用公开能力，内置与用户组件等价。
- 保持既有沙箱、CSP、请求校验、配额、令牌、布局与动效。输入、草稿、保存失败、冲突、无记录、无匹配、读取失败和来源缺失分开显示。
- 引用保留前向 id，反向关系统一计算；归档、回收站与永久删除分别处理，不静默级联删除其他记录和外部材料。
- 保留现有一万条、16 MiB、30 天回收站及单条预算；先测量再决定存储拆分。新类型与字段同步校验、检索、导出导入和 ID 重映射。
- `.dshboard` 保存看板，`.dshrecords` 保存记录与引用；不暗示外部文件已随包。旧包兼容，未知版本保留原文件并报错，导入预览后原子提交。
- 卡片保留有限摘要，长内容进入详情。浅深色、键盘、窄宽盒、长内容、减弱动效与性能按 [体验要求](scholar-experience.md) 验收。演示、截图和测试使用合成材料。

## 上游协作

学术能力保留在独立项目；通用布局、编辑、无障碍、性能与测试稳定性独立成逻辑提交。候选见 [清单](upstream-candidates.md)，准备贡献时重查上游基线、已合并内容及公开身份，仅移植通用改动并按上游规范验证。创建 Issue/PR、合并和发布仍依明确授权，不把整个学术主线合入上游。
