# 学术工作台实施计划

更新日期：2026-11-10。用户选择在独立项目中发展面向通信硕博的个人工作台，以混合方式记录，优先组会、行动项与小论文进度。

范围见 [产品规划](scholar-product.md)，术语见 [领域术语](scholar-domain.md)，视觉与流畅性要求见 [体验验收](scholar-experience.md)，长期方向见 D35。本文管理任务与完成条件；功能实施时一次只激活一个任务。当前会话只更新规划文档，未开始下列功能实现。

## 已有基础与证据边界

| 能力 | 已有基础 | 后续边界 |
|---|---|---|
| 独立身份 | 包名、双语 README、署名与许可；独立主线已保存 | 上游合并贡献后仍独立发展 |
| 学术看板 | 组会 Markdown、倒数、日历、入口、待办、里程碑、阅读清单的静态组合 | 尚无结构化组会历史、稿件档案与跨卡片行动项 |
| 文献订阅 | paper-feed、宿主 Atom、画廊和学术看板第四行 | 只读订阅；不表示已读、收藏或全文下载 |
| 编辑与材料 | 创建、内容编辑、源码预览、本地图片、看板导入导出 | 外部材料引用与领域记录备份须另行设计 |
| 通用布局 | 自由布局、整齐行列、尺寸契约与矩阵 | 新交互仍需回归与视觉确认 |

历史计划及验收线索已归档到 [2026-11-09 计划](history/PLAN-scholar-20261109.md)。文献订阅浅深色由用户于 2026-11-09 确认；发布前修复提交 `5687fb5` 的完整验收通过（1060 条单元、宿主冒烟与矩阵），收据在 `.debug/local-review/SCHOLAR_RELEASE/`。历史证据不覆盖本次文档或未来功能。文献卡暂停与重启恢复未单独验证，安装实测、云端 CI、标签和 npm 发布也不在本次文档验收内。

## 执行约定

- `S00` 等编号用于本计划排程，不是 guard 已激活任务号。开工核对实际分支、policy 和允许文件，本表不扩大源码修改范围。
- 每项任务先列文件范围、数据语义、空态与失败、迁移影响、验证步骤；缺少改变用户行为的决定时询问用户。
- 保留既有看板和种子；模板由用户选择添加，不自动迁移自由文本，不自动填入真实日期与进度。
- 文档、通用体验改进与领域功能分别形成可审阅改动。完成记录绑定当前指纹，历史成功记录不自动继承。
- 本次不修改 guard 规则或保护基线；AGENTS 属受保护文件，合法文档修改仍需如实报告指纹差异。

## 每项任务的验收与上游候选

- 源码任务执行对应回归与完整 verify，按 guard 的 verify → review-template → complete 记录真实证据。纯文档检查不冒充产品完整验收。

- 通用改进另记来源、上游基线、独立变更及回归；上游 PR 只有明确授权后创建，不直接合并学术主线。
- 交接记录完成项、未执行项、阻碍和下一步。代码指纹变化后，旧收据仅作历史证据。
