## 2. 请求与 Atom 契约

- `request.format` 省略时保持 JSON；Atom 的解析结果、数组归一化、缺失字段与错误语义在契约文档及类型中一致。
- XML 仅由成熟库解析；限制响应体、解析开销与实体扩展，验证 Atom 根元素和命名空间，拒绝非法 XML、非 Atom 内容及异常结构。
- 保持原主机授权、地址检查、重定向策略、超时、取消和限额。分类值严格校验并正确编码，不能让 props 改变目标主机或注入额外查询参数。
- 缓存隔离要包含影响响应解释的请求配置；核查相同 URL 不同 format 的串用、权限变化与失败后缓存行为。
- [x] JSON 向后兼容、有效 Atom、空 feed、单条与多条、缺字段、非法结构、实体攻击、超限正文、超时取消和权限拒绝均有回归。
- [x] 新依赖在锁文件与 THIRD_PARTY.md 记录版本、来源、许可及随包分发的传递依赖；不遗漏 fast-xml-parser。

## 3. 卡片交互与生命周期

- 分类和条数由设置驱动；呈现加载、空结果、失败、成功与刷新状态，不能把请求失败显示成“没有论文”。
- 标题、作者、日期、摘要按纯文本处理；论文链接限制为预期 arXiv HTTPS 地址，经宿主打开，拒绝外部内容提供的任意协议与主机。
- 明确提交日期的时区和展示规则，长标题、多个作者及异常日期不破坏布局；中英文及浅深色均可读，键盘能访问论文入口。
- 切换设置、刷新和销毁时处理过期结果，暂停或离开看板时停止不必要工作；恢复后按原刷新契约运行。
- [x] s、l 尺寸族都有 samples.json 样例，覆盖正常与长内容；空态与失败由状态判定回归覆盖。矩阵中无溢出与不可见控件。
- [x] 在独立宿主核查首次读数、手动重读与改分类后重读。确定性回归使用单元夹具；在线 arXiv 核查单独记录，不让外部服务可用性决定本地回归结果。
- 暂停恢复与重启恢复走既有的可见性生命周期（D6、D16），本轮没有改动它；文献追踪没有自己的计时器，数据由定时链按 `refresh.everyMs` 在有人看时读。
